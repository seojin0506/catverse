# 🐱 Catverse
고양이 일상과 정보를 기록하고 모아두는 아카이브형 고양이 라이프 웹 플랫폼
 
Catverse는 Cat과 Universe의 합성어로, 시각 중심의 구성과 커뮤니티 기능을 통해 사용자가 고양이 라이프를 쉽고 편안하게 이해하도록 돕는 개인 웹사이트 제작 프로젝트입니다.

## 🛠 기술 스택
 
**Frontend**
- HTML5
- CSS3 / Flexbox / Grid
- JavaScript (ES6)
- jQuery 3.7.1
- GSAP / ScrollTrigger
- Splitting.js
---
 
## ✨ 주요 기능
 
**🏠 메인 페이지**
- 비주얼 섹션: 텍스트 사이에 고양이 이미지가 삽입된 타이포그래피 레이아웃
- 스크롤 연동 콘텐츠 섹션: 스크롤 위치에 따라 이미지에 텍스트 오버레이 순차 활성화
- 프로필 / 콘텐츠 / 즐겨찾기 / 커뮤니티 섹션 스크롤 모션 애니메이션
- 헤더 색상 전환: 특정 섹션 진입 시 헤더가 흰색 → 검정으로 자동 변경
- 전체 화면 네비게이션 오버레이 (햄버거 메뉴)
- 드롭다운 서브 메뉴

## 👩‍💻 구현 상세

- 스크롤 시 텍스트와 이미지가 함께 반응하는 시각 중심 콘텐츠 구조
